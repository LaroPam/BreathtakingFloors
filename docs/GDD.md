# Breathtaking Floors — дизайн-документ

> Рабочее название совпадает с репозиторием. Пиксельный рогалик для браузера: Яндекс Игры и YouTube Playables.

## Одной фразой

Рыцарь с фонарём спускается по этажам башни, утонувшей во тьме. На каждом этаже нужно зажечь три жаровни,
пока со всех сторон лезет орда. Огнестрел наводишь сам, реликвии стреляют сами, а стихии реагируют друг с другом.

## Что берём у других и что добавляем

Цель — собрать лучшее из жанра и добавить своё, а не сделать клон.

| Откуда | Что берём | Как это выглядит у нас |
|---|---|---|
| Vampire Survivors, Halls of Torment | орда, кристаллы опыта, выбор 1 из 3 при уровне, автоматическое оружие | **реликвии** стреляют сами, до 5 слотов, 5 уровней каждая |
| Enter the Gungeon | ручное прицеливание, характер оружия, пули, которые надо читать | **пистолет-фонарь** с ручным прицелом, враги-стрелки, кольца и спирали пуль |
| Hades | рывок с неуязвимостью, «вкус» к сочетаниям | рывок-уклонение, после-образы |
| Danmaku-шмапы (Touhou) | **граз**: награда за пролёт впритирку к пуле | граз заряжает Выброс |
| Genshin Impact / Magicka | реакции стихий | 9 реакций между 6 стихиями |
| Slay the Spire | выбор пути с риском и наградой | после этажа — выбор из двух лестниц с модификаторами |
| Risk of Rain | давление времени: чем дольше, тем тяжелее | волны растут с каждой минутой на этаже |

### Наше новое: три крючка

1. **Свет как территория.** Этаж тёмный. Фонарь героя освещает небольшой круг, и только в свете уязвимы
   призраки. Жаровни нужно разжечь, простояв рядом ~2.6 с под натиском. Зажжённая жаровня даёт большое пятно
   света: враги в нём замедляются, а герою капает заряд Выброса. Но каждая зажжённая жаровня вызывает «прилив
   тьмы» — волну врагов со всех сторон. В итоге игрок не бегает кругами, как в обычном survivors: он решает,
   куда идти, когда и в каком порядке, и держит позицию.
2. **Граз → Выброс.** Пуля, пролетевшая рядом, даёт заряд. Пролёт сквозь пулю в рывке («идеальный граз») даёт
   много заряда. Полный заряд — **Выброс**: фонарь взрывается светом, наносит урон всем вокруг и превращает
   вражеские пули в кристаллы опыта. Это вознаграждает смелую игру вместо пассивного кайта.
3. **Реакции стихий.** У каждой реликвии своя стихия: огонь, лёд, гроза, яд, сияние, пустота. Статус на враге
   плюс другая стихия дают реакцию: *Перегрузка* (огонь + гроза, взрыв), *Раскол* (лёд + гроза, ×3.5 по цели),
   *Затмение* (сияние + пустота), *Чумной выброс*, *Проводник*, *Пар*, *Изморозь*, *Солнечная вспышка*, *Разлом*.
   Билд выбирают ради сочетаний, а не только ради чисел. Открытые реакции попадают в кодекс (меню паузы).

## Основной цикл

```
Этаж (2–5 минут)
 ├─ двигайся, целься, стреляй; реликвии работают сами
 ├─ собирай кристаллы → уровень → 1 из 3 (новая реликвия / уровень реликвии / характеристика)
 ├─ зажигай жаровни (каждая вызывает прилив тьмы)
 ├─ элита каждые ~45 с → сундук → 1 из 3 реликвий
 ├─ все жаровни горят → портал (каждый 3-й этаж: сначала босс «Великое Око»)
 └─ портал → выбор лестницы (риск / награда) → следующий этаж
Смерть → угли (мета-валюта) → Кузница (вечные улучшения) → новый забег
```

## Управление

| | Клавиатура и мышь | Геймпад | Сенсор |
|---|---|---|---|
| Движение | WASD / стрелки | левый стик | левый палец (плавающий стик) |
| Прицел и огонь | мышь, зажать ЛКМ (F — автоогонь) | правый стик (огонь сам), RT | правый палец; без него автоприцел по ближайшему |
| Рывок | Пробел / Shift / ПКМ | A / LB | кнопка «РЫВОК» |
| Выброс | E / Q | Y / RB | кнопка с процентом заряда |
| Пауза | Esc / P | Start | значок паузы |

## Содержимое прототипа

- **Герой:** рыцарь в стальных латах. Анимирован 3D-скелетом pixelfx: бег, стойка, рывок, отдача при ранении.
  Пистолет поворачивается за прицелом в руке скелета.
- **Враги (9):** слизень (прыгает), нетопырь (виляет), огненный череп (держит дистанцию, стреляет), око (кольца
  пуль), призрак (неуязвим вне света), огонёк (подлетает и взрывается, задевая и своих), элитный слизень
  (делится на три), элитный череп (веер из трёх пуль), босс «Великое Око» (спираль, кольца с прицельными
  залпами, призыв стаи, ярость ниже 50% HP).
- **Реликвии (6):** Угольная орбита, Ледяное копьё, Грозовая катушка, Фляга с ядом, Нимб, Сфера пустоты.
- **Характеристики (11):** урон, скорострельность, веер, пробитие, скорость, сердца, магнит, перезарядка рывка,
  заряд Выброса, крит, радиус фонаря.
- **Модификаторы лестниц (6):** Рой, Мрак, Чемпионы, Кровь, Узкая, Тихая.
- **Кузница (4):** Живучесть, Мощь, Притяжение, Наследие.

## Прогрессия и монетизация

- Угли за забег: этажи × 8 + убийства / 10 + бонусы за боссов, с множителем модификатора.
- Яндекс Игры: межстраничная реклама между забегами (SDK сам ограничивает частоту), награда за рекламу —
  одно возрождение за забег. Облачные сохранения через `player.setData`.
- YouTube Playables: без рекламы в прототипе, рекорд уходит через `engagement.sendScore`.

## Дорожная карта

1. **Вертикальный срез (готов):** всё перечисленное выше играется от титульного экрана до смерти.
2. **Чувство игры:** подобрать баланс по реальным сессиям, добавить раскачку камеры при попадании, звук
   разных стихий, анимацию смерти героя через актёрские эффекты pixelfx (`spawn/soul-rise`, `spawn/disintegrate`).
3. **Глубина:** второе оружие (дробовик, луч, ракетница — заготовки есть в `projectiles/` pixelfx), эволюции
   «реликвия + стихия пистолета», ещё 3–4 вида врагов, 2 босса, препятствия на этажах (колонны, ямы).
4. **Биомы:** каждые 3 этажа новая палитра пола и погода (`weather/*`: снег, пепел, споры).
5. **Мета:** второй герой (маг на скелете pixelfx с посохом), ежедневный забег с фиксированным сидом, таблица рекордов Яндекса.
6. **Релиз:** модерация Яндекса по чек-листу из `docs/TECH.md`, сертификация YouTube Playables.
